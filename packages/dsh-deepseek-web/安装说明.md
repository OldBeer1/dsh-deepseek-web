# DSH × DeepSeek 网页版插件 —— 安装说明（转发给朋友用）

这个插件给 DSH 加一个「DeepSeek 网页版」面板：在 DSH 里直接问 DeepSeek，
走的是 **chat.deepseek.com 的网页额度**，不消耗官方 API 的按量计费。

宿主端（Node）负责 PoW 求解与 SSE 转发，浏览器端画面板。**零依赖、无需构建。**

---

## 一、装之前先确认

| 项 | 要求 |
|---|---|
| DSH | 桌面版／同一套 Harness。本包是在 **DSH 0.2.0-rc.2** 上开发并逐项实测的；槽位名（`sidebar.panellist` / `main`）与 `webServer` 服务必须存在，否则面板不会出现 |
| 网络 | 需要能访问 `chat.deepseek.com` 与 `fe-static.deepseek.com`（首次会去下载官方的 PoW wasm 并缓存到本机） |
| 账号 | **你自己的** DeepSeek 账号。登录只需一次手机号 + 短信验证码 |

## 二、安装（3 步）

1. **把这个文件夹放到任意位置**（路径里最好别有空格），例如 `D:\dsh-plugins\dsh-deepseek-web`。

2. **让你自己的 DSH 装上它** —— 对 DSH 的助手说一句就行：

   > 把 `D:\dsh-plugins\dsh-deepseek-web` 这个目录作为插件包装进当前 profile。

   （它内部会调用 `plugin_manager install_bundle`，不要手写 profile 的 `package.json`，也不要自己跑 pnpm。）

3. **完全退出 DSH 再打开**（不是刷新页面）。
   宿主端的代码只在进程启动时加载一次，这一步不能省。

装好后：左侧图标栏会多一个图标 → 点开是面板。

## 三、登录（只做一次）

面板右上角 **设置** → 填手机号 → **发送验证码**。

- 如果提示"官方要求人机验证"（**大概率如此**）：这属于官方限制，插件代发不了。
  请在浏览器打开 `chat.deepseek.com`，点一次「获取验证码」，把收到的 6 位码填回面板 → 点 **登录**。
- 登录成功后，凭证只保存在**本机**（`%USERPROFILE%\.dsh\deepseek-web\config.json`），不会回传到浏览器。

## 四、必须知道的风险

1. **这是逆向调用，不是官方接口。** 官方一改版就可能失效；请用小号，别用主力号。
2. **登录 token 等于账号的完整凭证。** 不要把它发给任何人、不要贴到聊天里。
   → 所以：**转发这个包时，别把 `%USERPROFILE%\.dsh\deepseek-web\` 这个目录一起发**（那里面有 token）。
   本压缩包里不含任何凭证。
3. 有风控：不要并发轰炸、不要脚本化连续提问。
4. 无任何担保，出问题自己担。

## 五、出问题先看这里

| 现象 | 怎么办 |
|---|---|
| 侧边栏没有图标 | 确认已**完全重启** DSH；再确认第 2 步的安装真的成功了 |
| 面板报 `仅允许本机同源访问` | 说明请求没带上浏览器的同源标记。把报错里的 `reason` 字段发出来（403 正文里有），能直接定位是哪一条判定没过 |
| 面板报 `HTTP 404: not found` | 宿主端还是旧代码／没装上：需要重启 DSH |
| 回答没有"思考/搜索"过程 | 确认发送时勾了「深度思考」「联网搜索」；这两个勾选**按对话分别记忆** |
| 登录一直失败 | 先照着第三步用官网拿码；错误码会被翻成人话（验证码过期／次数过多／设备风险等） |
