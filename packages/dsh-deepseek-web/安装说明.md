# 安装说明 · Installation Guide

**中文** | [English](#english)

这个插件给 DSH 加一个「DeepSeek 网页版」面板：在 DSH 里直接问 DeepSeek，
走的是 **chat.deepseek.com 的网页额度**，不消耗官方 API 的按量计费。

宿主端（Node）负责 PoW 求解与 SSE 转发，浏览器端画面板。**零依赖、无需构建。**

---

## 一、装之前先确认

| 项 | 要求 |
|---|---|
| DSH | 桌面版。本包在 **DSH 0.2.0-rc.2** 上开发并逐项实测；面板依赖 `sidebar.panellist` / `main` 两个槽位名与 `webServer` 服务 |
| 网络 | 能访问 `chat.deepseek.com` 与 `fe-static.deepseek.com`（首次会去下载官方 PoW wasm 并缓存到本机） |
| 账号 | **你自己的** DeepSeek 账号。登录只需一次手机号 + 短信验证码 |

## 二、安装

**最简（推荐）**：把仓库地址发给你自己的 DSH 助手，让它克隆并安装：

> 把 `https://github.com/OldBeer1/dsh-deepseek-web` 克隆下来，装上其中的插件包（在 `packages/dsh-deepseek-web`）。

**不想用 git**：下载 ZIP 解压后，在仓库根目录跑 `install.ps1`（Windows）或 `install.sh`（macOS/Linux），
它会把插件放到 `%DSH_HOME%\plugins\dsh-deepseek-web` 并把该说的话放进剪贴板。

**手动**：把 `packages/dsh-deepseek-web` 放到任意目录，然后对 DSH 助手说：

> 把 `<那个目录>` 作为插件包装进当前 profile。

> 路径**不必**避开空格 —— 本插件就在 `C:\Users\Old Beer\...` 这种带空格的路径下开发并实测。

**无论走哪条路，最后都要：完全退出 DSH 再打开**（不是刷新页面）。
宿主端代码只在进程启动时加载一次；插件开关、卸载重装都**不会**重载它。

## 三、登录（只做一次）

面板右上角 **设置** → 填手机号 → **发送验证码**。

- 如果提示"官方要求人机验证"（**大概率如此**）：这属于官方限制，插件代发不了。
  请在浏览器打开 `chat.deepseek.com`，点一次「获取验证码」，把收到的 6 位码填回面板 → 点 **登录**。
- 登录成功后，凭证只保存在**本机**（`%USERPROFILE%\.dsh\deepseek-web\config.json`，权限 0600），不会回传给浏览器页面。

## 四、必须知道的风险

1. **这是逆向调用，不是官方接口。** 官方一改版就可能失效；请用**小号**，别用主力号。
2. **登录 token 等于账号的完整凭证。** 不要把它发给任何人、不要贴到聊天里。
   本仓库不含任何凭证；`%USERPROFILE%\.dsh\deepseek-web\` 目录也**不要**分享。
3. 有风控：不要并发轰炸、不要脚本化连续提问。
4. 无任何担保，出问题自己担。

## 五、出问题先看这里

| 现象 | 怎么办 |
|---|---|
| 侧边栏没有图标 | 确认已**完全重启** DSH；再确认安装那一步真的成功了 |
| 面板报 `仅允许本机同源访问` | 请求没带上浏览器的同源标记。把报错正文里的 `reason` 字段发出来，能直接定位是哪条判定没过 |
| 面板报 `HTTP 404: not found` | 宿主端还是旧代码／没装上：需要重启 DSH |
| 回答没有"思考/搜索"过程 | 确认发送时勾了「深度思考」「联网搜索」；这两个勾选**按对话分别记忆** |
| 登录一直失败 | 先照第三节用官网拿码；错误码会被翻成人话（验证码过期／次数过多／设备风险等） |
| 更新后行为没变 | 前端刷新即可，**宿主必须重启**。设置页底部那行版本号就是用来确认这件事的 |

# Installation Guide

[中文](#安装说明--installation-guide) | **English**

This plugin adds a "DeepSeek Web" panel to DSH: ask DeepSeek from inside DSH, spending your
**chat.deepseek.com web quota** instead of the metered official API.

The host half (Node) solves the proof-of-work and relays SSE; the browser half draws the panel.
**Zero dependencies, no build step.**

---

## 1. Before you start

| Item | Requirement |
|---|---|
| DSH | Desktop. Built and tested against **DSH 0.2.0-rc.2**; the panel relies on the `sidebar.panellist` / `main` slots and the `webServer` service |
| Network | Access to `chat.deepseek.com` and `fe-static.deepseek.com` (the official PoW wasm is downloaded once and cached locally) |
| Account | **Your own** DeepSeek account. Signing in takes one phone number + one SMS code |

## 2. Install

**Simplest (recommended)** — give the repo URL to your own DSH assistant and let it clone and install:

> Clone `https://github.com/OldBeer1/dsh-deepseek-web` and install the bundle inside it (it is at `packages/dsh-deepseek-web`).

**No git?** Download the ZIP, unpack it, and run `install.ps1` (Windows) or `install.sh` (macOS/Linux)
from the repository root. It copies the plugin to `%DSH_HOME%\plugins\dsh-deepseek-web` and puts the
sentence you need onto your clipboard.

**Manual** — put `packages/dsh-deepseek-web` anywhere, then tell your DSH assistant:

> Install the bundle at `<that directory>` into the current profile.

> The path does **not** need to avoid spaces — this plugin was developed and tested from
> `C:\Users\Old Beer\...`, which contains one.

**Whichever route you take, finish with: quit DSH completely and reopen it** (a page refresh is not
enough). The host half loads once, at process startup; toggling the plugin or reinstalling it does
**not** reload it.

## 3. Sign in (once)

**Settings** in the top-right of the panel → phone number → **send code**.

- If it says a captcha is required (**very likely**): that is an official restriction and the plugin
  cannot send the SMS for you. Open `chat.deepseek.com` in a browser, click "Get code" once, then
  paste the 6-digit code into the panel and press **Sign in**.
- The credential is stored only on your machine
  (`%USERPROFILE%\.dsh\deepseek-web\config.json`, mode 0600) and is never sent back to the browser page.

## 4. Risks you must know

1. **Unofficial and reverse-engineered.** Any change on DeepSeek's side can break it.
   Use a **secondary account**, not your main one.
2. **The login token is a full account credential.** Never share it or paste it into a chat.
   This repository contains no credentials; do **not** share your
   `%USERPROFILE%\.dsh\deepseek-web\` directory either.
3. Rate limits are real: no concurrent hammering, no scripted bulk prompting.
4. No warranty. You bear the consequences.

## 5. Troubleshooting

| Symptom | What to do |
|---|---|
| No icon in the sidebar | Make sure you **fully restarted** DSH, and that the install step actually succeeded |
| Panel says "loopback same-origin access only" | The request carried no browser same-origin marker. Send us the `reason` field from the error body — it pinpoints which check failed |
| Panel says `HTTP 404: not found` | The host half is stale or not installed: restart DSH |
| No reasoning/search trace in answers | Check that "Deep thinking" / "Web search" were enabled when sending; both are remembered **per conversation** |
| Sign-in keeps failing | Use the browser code route from section 3; error codes are translated into plain language (code expired / too many attempts / device risk, etc.) |
| Behaviour unchanged after an update | Refresh for the client half, **restart for the host half**. The version line at the bottom of the settings page tells you which is which |
